== MQTT Space

https://mqtt.org/[MQTT] is a lightweight messaging protocol commonly used for IoT (https://en.wikipedia.org/wiki/Internet_of_things[Internet of Things]) applications. 
The protocol offers https://en.wikipedia.org/wiki/Publish%E2%80%93subscribe_pattern[publish-subscribe] messaging and a wildcard-based addressing scheme that conveniently maps to the 
URI address space.

++++
<!-- 🐖
*/m/iot/space/mqtt
--> 
++++

The MQTT space is a client of the MQTT broker referenced by `host`. This client maintains a router-detached caching space 
(default is `mem::T`) which maintains synchronization with that subset of the broker identified in the MQTT space's routing table.

++++
<1> the `mqtt:T` space maintains a subset of the larger address space of the broker.
<2> the `mqtt:T` space can be queried like a database due to mqtt persist being enabled by default.
<3> the `mqtt:T` space addresses can be subscribed to and receive updates via `inst` callbacks.
