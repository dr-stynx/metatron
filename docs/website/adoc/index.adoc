            <div class="feature-modal">
                <p><b class="metatron-name">mtron</b> (pronounced /ɛm.trɒn/) is the primary query and transformation language for the metatron virtual machine. It provides a type-safe environment for processing data across heterogeneous spaces.</p>
                <img src="images/modal/mtron-modal.svg" class="img-fluid mb-3 icon-color" style="width: 500px; display: block; margin: auto;"/>
                <p>highlights include:</p>
                <ul>
                    <li>every expression is an element of an algebraic ring, where function composition and function parallelization being * and +, respectively.</li>
                    <li>structural typing allows, e.g., a graph vertex to act as a row in a relational database and vice versa.</li>
                    <li>uris and code are first class objects</li>
                </ul>

            <div class="feature-front">
                metatron <b class="metatron-name">objs</b> exist in a single, unified uri address space where processes can seamlessly traverse across different data sources.
            </div>
            <div class="feature-modal">
                <p>The <b class="metatron-name">fURI</b> (<i>functional</i> URI) is the cornerstone of metatron's memory model. Every piece of data, regardless of its underlying storage, is addressed via a consistent URI scheme. The primary ramification is that any iota of data can refer to any other iota of data regardless of its physical location and underlying storage system and format. For instance, a line of text in a <code>.txt</code> file on a hard drive can reference some specific tag in an html page on the web. Atop the space-based uri graph, there exists a uri-aware machine capable of processing that data in a storage-agnostic manner.
                </p>
                <img src="images/modal/furi-modal.svg" class="img-fluid mb-3 icon-color" style="width: 500px; display: block; margin: auto;"/>
                <p>highlights include:</p>
                <ul>
                    <li>universal namespace across databases, file systems, APIs, microcontrollers, in-memory data structures, etc.</li>
                    <li>the subsequent link structure supports complex traversals across a wide range of data sources -- all within the same mtron expression.</li>
                    <li>query processors enrich space semantics with useful features such as constants, uri typing, pubsub notifications, and more.</li>
                </ul>
            </div>
            <script type="text/javascript">featurePanel("uri_feature");</script>

                file systems, large language model catalogs, and more. Spaces can range from the small (a microprocessor's on-board memory), to the large (the world wide web).</p>
