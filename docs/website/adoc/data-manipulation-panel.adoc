=====

There are 3 ways to access data.

. **direct reference**: every piece of data is associated with a unique URI.
. **pattern matching**: pattern based URIs enable accessing entire branches of a URI address space.
. **indirect reference**: data can reference other data either through container or URI pointers.

++++
<!-- 🐖
x -> [a=>1,b=>[c=>2,d=>[3,4,5]],e=>6]
*x
*x/b/+
*x>>b>>d>>+
-->
++++
