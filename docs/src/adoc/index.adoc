Metatron is a ring-oriented programming language and virtual machine. A https://en.wikipedia.org/wiki/Ring_(mathematics)[ring] is an __algebraic structure__ where elements of the structure can be composed using two binary operators `+` (plus) and `*` (mult). 

```
a+0 = a
a*1 = a
a-a = 0
a*(b+c) = ab + ac 
(b+c)*a = ba + ca
```
