## Instruction Reference

This section provides a comprehensive reference of all instructions available in the core `m` instruction set, organized by the type they operate on.

### General Instructions (All Types)

These instructions work on any object type:

[cols="1,1,2,2", options="header"]
|===
|Instruction |Sugar |Description |Example

|`id()`
|`_`
|Identity function - returns the object unchanged
|`5._` → `5`

|`eq(obj)`
|
|Equality test - returns true if objects are equal
|`5.eq(5)` → `true`

|`is(eq(obj))`
|`?=`
|Type-safe equality test
|`5?=5` → `true`

|`is(gt(obj))`
|`?>`
|Type-safe greater than
|`5?>3` → `true`

|`is(gte(obj))`
|`?>=`
|Type-safe greater than or equal
|`5?>=5` → `true`

|`is(lt(obj))`
|`?<`
|Type-safe less than
|`3?<5` → `true`

|`is(lte(obj))`
|`?<=`
|Type-safe less than or equal
|`3?<=3` → `true`

|`is(neq(obj))`
|`?!=`
|Type-safe not equal
|`5?!=3` → `true`

|`isa(type)`
|`?`
|Type check - returns true if object is of given type
|`5?int` → `true`

|`as(type)`
|
|Type cast - converts object to given type
|`'5'.as(int)` → `5`

|`get(key)`
|`./`
|Get value by key (for records/maps)
|`[a:1,b:2]./a` → `1`

|`put(key,value)`
|
|Put key-value pair (for records/maps)
|`[a:1].put('b',2)` → `[a:1,b:2]`

|`split()`
|`-<`
|Split stream into branches
|`5-<` → splits into parallel branches

|`merge()`
|`>-`
|Merge branches into single stream
|`{1,2,3}>-` → merges branches

|`barrier()`
|`>|`
|Synchronization barrier - waits for all branches
|`stream>|` → waits for completion

|`choose()`
|`-<|`
|Non-deterministic choice between branches
|`{1,2,3}-<|` → picks one branch

|`q()`
|
|Get coefficient of object
|`int{5}::3.q()` → `5`

|`qSet(n)`
|
|Set coefficient of object
|`3.qSet(5)` → `int{5}::3`

|`error(msg)`
|
|Create error/failure object
|`5.error('bad value')` → error object

|`explain()`
|
|Get explanation/trace of computation
|`5.plus(3).explain()` → shows computation trace

|`select(keys)`
|`==`
|Select/project specific keys from record
|`[a:1,b:2,c:3]=={'a','b'}` → `[a:1,b:2]`

|`where(pred)`
|`?==`
|Filter stream by predicate
|`{1,2,3,4}?==gt(2)` → `{3,4}`

|`matches(regex)`
|`=~`
|Test regex match
|`'hello'=~'h.*o'` → `true`

|`is(matches(regex))`
|`?=~`
|Type-safe regex match
|`'hello'?=~'h.*o'` → `true`

|`at(index)`
|`@`
|Get element at index
|`{1,2,3}@1` → `2`

|`within(range)`
|`_/`
|Test if value is within range
|`5_/{1,10}` → `true`

|`ref(name)`
|`->`
|Create reference/binding
|`x->5` → binds x to 5

|`block(inst)`
|`\|`
|Execute instruction block
|`5\|plus(3)` → `8`

|`end()`
|`;`
|End of instruction sequence
|`5.plus(3);` → terminates

|===

### Notes on Instruction Usage

**Sugar Syntax**: The "Sugar" column in the tables above shows the shorthand notation for each instruction. Sugar syntax makes code more concise:

```mtron
// Verbose
5.plus(3).mult(2)

// Sugar
(5+3)⋅2
```

**Common Sugar Patterns**:

- Arithmetic: `+`, `-`, `⋅` (multiplication)
- Navigation: `>>` (deeper), `<<` (up), `./` (get)
- Stream control: `>-` (merge), `-<` (split), `>|` (barrier)
- Dereferencing: `*` (from), `!` (auto), `!*` (auto-from)
- Type checking: `?` (isa), `?=` (is-equal), `?>` (is-greater-than)
- Filtering: `?==` (where), `==` (select), `%==` (groupBy)
- Pattern matching: `=~` (matches), `?=~` (is-matches)

**Placeholder `_`**: The underscore represents identity and enables partial application:

```mtron
{1,2,3}.map(plus(_))      // adds each element to itself
{1,2,3}.map(mult(2))      // multiplies each by 2
{1,2,3}.map(_)            // identity - returns {1,2,3}
```

**Chaining**: Instructions chain naturally with both verbose and sugar syntax:

```mtron
// Verbose
{1,2,3,4,5}.filter(gt(2)).map(mult(2)).sum()

// Mixed (common style)
{1,2,3,4,5}?==gt(2).map(mult(2)).sum()

// Result: 24
```

**Coefficients**: All objects can have coefficients for interference patterns:

```mtron
int{5}::3+int{2}::4       // coefficient arithmetic
int{5}::3++int{2}::4      // monoid plus (coefficient merge)
```

**Context-Dependent Operators**: Some sugar symbols have different meanings based on context:

- `*` → `from()` when prefix (dereference URI), `mult()` when infix
- `>>` → `rshift()` for navigation, can also be used for nested access
- `==` → `select()` for projections, `eq()` for equality (with `?=`)

**Type-Safe Comparisons**: The `?` prefix creates type-safe comparison operations:

```mtron
5?=5          // is(eq(5)) - type-safe equality
5?>3          // is(gt(3)) - type-safe greater than
'hello'?=~'h.*'  // is(matches('h.*')) - type-safe regex match
```
